# Diplom_work

Диплом описание


Сайт для создания, организации и публикации технической документации, баз знаний и электронных книг

Похожие сайты:
GitLab
Bitbucket
GitVerse

Функционал

Есть бешенное желание написать сайт, на котором пользователь сможет

- по фильтру искать необходимые документы из базы данных
- создавать документацию
- получать ее по запросу
- удалять ее по идентификатору
- редактировать документацию
- по возможности привязать это к эл. почте или мессенджеру для оперативного уведомления
